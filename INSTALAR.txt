RUTA EORZEA — INSTALACIÓN Y ACTUALIZACIONES (WINDOWS)

REQUISITOS
- FFXIV para Windows iniciado con XIVLauncher y Dalamud API 15 compatible.
- vnavmesh instalado y activado, con el motor de caminos preparado (Ready).
- Gubal es opcional: traduce el juego, pero no es necesario para las rutas.
- No necesitas Visual Studio ni el SDK de .NET para instalar el addon.

MÉTODO RECOMENDADO: REPOSITORIO DE DALAMUD
1. Si falta vnavmesh: /xlsettings > Experimental > Custom Plugin Repositories.
   Añade https://puni.sh/api/repository/veyn, pulsa + y guarda.
   En /xlplugins, busca vnavmesh e instálalo/actívalo.
2. En la misma sección de repositorios personalizados añade:
   https://raw.githubusercontent.com/jorgestmerchant/RutaEorzea/main/pluginmaster.json
   Pulsa +, guarda y actualiza el catálogo en /xlplugins.
3. Busca Ruta Eorzea e instálalo. La portada de GitHub NO sustituye al
   enlace completo del archivo pluginmaster.json.
4. Marca una misión o usa M > clic derecho > Crear ruta hasta aquí.

ACTUALIZACIONES
Las versiones nuevas publicadas en GitHub aparecerán en /xlplugins.
Actualiza desde allí; no necesitas reemplazar DLL manualmente.
La instalación automática depende de los ajustes de Dalamud del usuario.
Los parches del juego o Dalamud pueden requerir una nueva versión.

SI USABAS EL ZIP DE DESARROLLO
Desactiva esa copia en /xlplugins y quita su ruta de Dev Plugin Locations
antes de instalar desde el catálogo. No cargues ambas copias a la vez.
El nombre interno del plugin sigue siendo RutaEorzea.

MÉTODO MANUAL ALTERNATIVO (SIN ACTUALIZACIONES DEL CATÁLOGO)
1. Extrae el ZIP completo en una carpeta permanente, por ejemplo:
   C:\FFXIV-Plugins\RutaEorzea
   Mantén juntos la DLL, el JSON y la carpeta images.
2. /xlsettings > Experimental > Dev Plugin Locations.
   Añade C:\FFXIV-Plugins\RutaEorzea\RutaEorzea.dll, pulsa + y guarda.
3. /xlplugins > Dev Tools / Installed Dev Plugins > activar Ruta Eorzea.
4. Para actualizar esta copia manual, cierra el juego y reemplaza los archivos
   del ZIP en la misma carpeta. Para actualizar desde el catálogo, migra antes
   según las instrucciones anteriores.

USO
- Casilla junto a una misión principal o secundaria: seguir/detener.
- M > clic derecho en punto o icono: ruta personalizada.
- Ctrl + clic derecho: bandera nativa del juego.
- /ruta o engranaje del minimapa: ajustes. /ruta parar: detener.
- La línea del terreno viene apagada. La ruta se ve en el minimapa y en M.
- El nivel entre paréntesis usa verde (adecuado), naranja (3–4 niveles más),
  rojo (5 o más), gris (6 o más niveles por debajo). No calcula EXP.

LÍMITES
El mapa grande muestra el tramo del mapa actual. Los viajes se calculan
por salidas a pie compatibles. Transportes, pisos superpuestos y algunas
misiones requieren intervención. Tú mueves al personaje.
Consulta README.md y LEEME.md para más detalles.
